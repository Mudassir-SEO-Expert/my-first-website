# Sitemap and wireframes

- `/`: navigation → exact agreed hero → working principles → five services + creative → differentiators → four-step process → concepts → audience + honest case-study link → FAQ → contact CTA → footer.
- `/about`: purpose → founder skill profile and creative collaboration → remote service audience → CTA.
- `/services`: service cards → creative support → FAQ → CTA.
- `/services/web-development`, `/services/e-commerce-development`, `/services/software-development`, `/services/seo`, `/services/digital-marketing`: service-specific hero → approach + scope → related service links → CTA.
- `/portfolio`: labelled concepts → permissions explanation → CTA.
- `/case-studies`: honest empty state → concepts/contact links.
- `/blog`: article index → three original full editorial pieces; no fabricated publication dates.
- `/contact`: project invitation + actual approved mailbox + call scheduling explanation → validated email draft form.
- `/privacy-policy`, `/terms`: readable legal information and contact.
- `/sitemap.xml`, `/robots.txt`, `/opengraph-image`: technical discovery and social sharing.

## Shared component wireframe

Desktop: sticky wordmark | About | descriptive Services dropdown | Our work | Insights | CTA | theme/motion.
Mobile: wordmark | preferences | menu; stacked expandable links with inline service descriptions. No modal focus trap needed because navigation is nonmodal. Escape closes dropdown first, then mobile navigation, returning focus to the controlling button.

Desktop hero: left editorial copy and actions; right cinematic growth sculpture. Mobile: copy/actions then illustration. Sections stack with readable spacing; cards reduce from three columns to one; process and values use two columns on mobile. Contact moves from two columns to one.

Footer: brand/location truth → expertise → page links → enquiry path → legal links.
